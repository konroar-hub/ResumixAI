# Resume Tailor

AI-powered resume tailoring application built with React, Vite, TypeScript, and Tailwind CSS.

## Features & Implementation
- **Vite Runtime**: Fast local development & build system.
- **Experience Feed View**: Structured visual display of experience entries.
- **YAML Storage**: Import, edit, and store resume configuration via master YAML data format.
- **PDF Exporter**: Live preview and export functionality to generate professional resume PDFs.
- **AI Chat & Assist Interface**: In-progress interactive AI chat assistant for custom prompt-based tailoring.

## Local Setup & Development Instructions

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` (included with Node.js)

### Installation
1. Open your terminal and navigate to the project directory:
   ```bash
   cd "D:/Projects/Resume Tailor"
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the local development server with hot-reload:
```bash
npm run dev
```
By default, Vite will start the app at `http://localhost:5173`. Open this URL in your web browser.

### Building for Production
To typecheck and build static distribution assets:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
